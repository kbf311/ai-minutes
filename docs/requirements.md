# 要件定義書：ローカル音声録音・話者分離付き文字起こしシステム

---

## 1. システム概要

本システムは、Windows PC 上で動作するスタンドアロン型の Python アプリケーションです。

マイク（またはステレオミキサー等のオーディオ入力デバイス）からの音声録音を行い、その録音データ（または既存の音声ファイル）に対して **文字起こし（ASR）** と **話者分離（Diarization）** を実行し、「誰がいつ発言したか」を整理した議事録テキストを出力します。

---

## 2. システム構成と採用技術

| 役割 | 採用技術 / ライブラリ | 備考 |
| --- | --- | --- |
| **実行環境** | Windows 11 / 10 (64-bit), Python 3.10〜3.12 | CUDA 12.x 対応の NVIDIA GPU（推奨） |
| **音声録音** | `sounddevice`, `soundfile` | 16kHz モノラル WAV 出力 |
| **話者分離** | `Nemotron-3-Diarization` (`transformers` / `torch`) | NVIDIA 製 Sortformer 採用モデル（最大8話者） |
| **音声認識 (ASR)** | `faster-whisper` (large-v3 または large-v3-turbo) | CTranslate2 ベースで高速処理 |
| **アライメント・マージ** | 自作 Python ロジック | タイムスタンプ重複率による話者割り当て |
| **UI（操作形態）** | CLI（コマンドライン）、または簡易 GUI（`gradio` / `PyQt`） | 初期フェーズは CLI スクリプトで実装 |

## 3. 機能要件

### 3.1. 音声録音機能

* **入力デバイス選択**: PC に接続されている入力デバイス（マイク、仮想オーディオミキサー等）を指定可能であること。
* **録音制御**:
* キーボード操作（Enterキー押下や `Ctrl+C`）による「録音開始」「録音停止」の制御。


* **音声フォーマット**:
* サンプリングレート: `16,000 Hz`
* チャンネル: `モノラル` (1ch)
* 形式: `WAV (PCM 16-bit)`
*※Nemotron-3-Diarization および Whisper がネイティブに求める形式に固定し、前処理の変換コストをゼロにします。*



### 3.2. 音声認識（文字起こし）機能

* `faster-whisper` を使用し、音声からテキストと発話タイムスタンプ（`start`, `end`, `text`）を取得。
* 日本語会議に対応するため、言語設定を `ja` に指定可能。
* GPU（CUDA / FP16）による高速推論。GPU非搭載環境では CPU / INT8 へのフォールバックを考慮。

### 3.3. 話者分離（Diarization）機能

* `Nemotron-3-Diarization`（Hugging Face 版）を使用。
* 各セグメントに対して話者ラベル（`Speaker 0`, `Speaker 1`...）と活動区間（`start`, `end`）を推論。
* 録音済みファイル全体に対するオフライン処理（30.4秒バッファ相当）で高精度な判定を行う。

### 3.4. タイムスタンプ統合（アライメント）機能

* Whisper が出力したテキストセグメントの区間 `[W_start, W_end]` と、Nemotron が出力した話者区間 `[D_start, D_end]` の時間的重複率（Intersection over Union または 重複秒数）を計算。
* 重複が最大となる話者 ID をその発言に紐付け。
* 同一話者が連続して発言している場合は、テキストを1行に結合して可読性を高める。

### 3.5. 出力機能

* 処理結果を以下のフォーマットでファイル出力（`.txt` または `.md`）：
```markdown
[00:00:02 - 00:00:08] 話者 0: 本日の定例ミーティングを始めます。
[00:00:09 - 00:00:15] 話者 1: よろしくお願いします。議題の1点目についてですが…

```


* オプションとして、話者情報を含んだ字幕ファイル（`.srt`）や JSON 形式での出力にも対応可能とする。

---

## 4. 非機能要件

### 4.1. 動作環境・ハードウェア前提

* **OS**: Windows 10 / 11 64-bit
* **GPU**: NVIDIA RTX 3060 以上（VRAM 8GB 以上推奨）
* Nemotron-3 (0.1B) は極めて軽量ですが、Whisper (large-v3) と同時に GPU メモリ上に展開するため、8GB 以上の VRAM があると快適に動作します。


* **CPU / メモリ**: 16GB 以上のシステム RAM

### 4.2. 処理速度

* 1時間の録音音声に対し、GPU 利用時に **5分以内（RTX 3060/4060想定）** で文字起こしおよび分離処理が完了すること。

## 6. 開発フェーズ・実装ステップ

1. **フェーズ 1：環境構築と依存パッケージの導入**
* Python 環境（venv / conda / uv）の準備
* CUDA 版 PyTorch、`faster-whisper`、`sounddevice`、`transformers` (GitHub main版) のセットアップ


2. **フェーズ 2：録音モジュール作成**
* コンソールから録音の開始・停止を行い、16kHz モノラル WAV を出力するスクリプトの実装


3. **フェーズ 3：Nemotron + Whisper 結合モジュール作成**
* WAV ファイルを読み込み、分離と文字起こしを実行してタイムスタンプを突き合わせるロジックの実装


4. **フェーズ 4：一連パイプラインの統合**
* 「録音 → 自動で文字起こし → テキスト出力」まで一気通貫で動く CLI スクリプトの完成
